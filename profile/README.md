# CrystalWorlds.Media

Your films, shows and games on one wall, in the browser.

**[crystalworlds.media](https://crystalworlds.media)**

A free, non-commercial preservation project. It hosts no games, firmware or
films: everything plays from your own files and servers.

- **[client](https://github.com/crystalworlds/client):** the site, with the
  source for the Game Boy emulator. Free to use, under the
  [project licence](https://github.com/crystalworlds/client/blob/main/LICENSE).

This is a fan project. It is not affiliated with, endorsed by or sponsored by
Nintendo, Atari or any other maker of the machines shown.
